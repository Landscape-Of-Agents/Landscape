# Leadership

CEOs, CTOs, and boards need to know whether the agent program is safe and paying off, with numbers
that hold up in an audit.

## What you get

| Question | Answered from | Status |
|---|---|---|
| Are agents safer than last quarter? | near misses per thousand actions, bypasses, accidents | data exists; the report is to build |
| Where can agents be trusted with more? | earned-autonomy proposals per area, from evidence, signed by a person | to build |
| How much of our critical code is under signed rules? | governed coverage | data exists; the report is to build |
| What is agent work worth? | cost per verified change | to build |
| Can we show human oversight to auditors and insurers? | signed period exports of controls and evidence | to build |

## How decisions are split

| The system | Examples |
|---|---|
| **Decides by itself** (bounded, reversible, already authorized) | deny an action that breaks a rule; quarantine a session after a bypass; route a gap to its owner |
| **Proposes for a person** | new rules, wider autonomy, a published skill, a learned checklist |
| **Never decides** | weakening or removing a rule; publishing what it proposed; releasing a quarantine; decisions about people |

Silence never means yes: an unanswered approval parks or denies the action.

## Numbers you can trust

Unmeasured is never zero; every rate shows its denominator and its unknowns; numbers count only what
the viewer may see, with at least 3 cases; co-occurrence is never presented as cause.
