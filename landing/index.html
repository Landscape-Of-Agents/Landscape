What is Crane

Coding agents edit files and run commands faster than anyone can review them, and a prompt is not a rule. Crane turns what may change into signed contracts and enforces them where the agent acts.

  • Preserve and target. Lines agents must not touch, and lines they must change.
  • Checked before it runs. Hooks for Claude Code, Codex, Copilot CLI, and Gemini CLI.
  • Evidence. Signed, hash-chained records of what each agent did.

Install

curl -LO https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-x86_64-unknown-linux-gnu.tar.gz
tar -xzf crane-{tag}-x86_64-unknown-linux-gnu.tar.gz
sudo mv crane-{tag}-x86_64-unknown-linux-gnu/crane /usr/local/bin/
curl -LO https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-aarch64-apple-darwin.tar.gz
tar -xzf crane-{tag}-aarch64-apple-darwin.tar.gz
xattr -d com.apple.quarantine crane-{tag}-aarch64-apple-darwin/crane
sudo mv crane-{tag}-aarch64-apple-darwin/crane /usr/local/bin/
Invoke-WebRequest https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-x86_64-pc-windows-msvc.zip -OutFile crane.zip
Expand-Archive crane.zip -DestinationPath "$env:LOCALAPPDATA\Crane"
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$env:LOCALAPPDATA\Crane\crane-{tag}-x86_64-pc-windows-msvc", "User")

Then, in your repository:

crane repo --https https://github.com/OWNER/REPO
crane init
crane checkpoint baseline
crane agent install --profile claude
