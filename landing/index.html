What is Crane

Agents move fast. Crane keeps them inside the lines.

Coding agents now edit files, run commands, and touch code that matters. Reviewing every change afterwards does not scale, and a prompt is not a rule. Crane turns what may change into signed contracts and enforces them at the point where the agent acts.

⛨

Preserve and target

Mark lines an agent must not change, and lines it must change. Markers move with the code; the registry is signed.

⌁

Checked before it runs

Hooks for Claude Code, Codex, Copilot CLI, and Gemini CLI decide every tool call and catch shell bypasses afterwards.

▦

Zones and flows

Give risky code an autonomy ceiling and guidance, and connect zones into flows that stay acyclic.

⛓

Evidence you can trust

Hash-chained events and signed uploads show what each agent did, what was denied, and why.

Setup

Install in a minute

Put crane on your PATH, then set it up once per repository. Git is required; gh is used by crane github.

curl -LO https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-x86_64-unknown-linux-gnu.tar.gz
tar -xzf crane-{tag}-x86_64-unknown-linux-gnu.tar.gz
sudo mv crane-{tag}-x86_64-unknown-linux-gnu/crane /usr/local/bin/
crane --version
# Apple silicon; use x86_64-apple-darwin on Intel
curl -LO https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-aarch64-apple-darwin.tar.gz
tar -xzf crane-{tag}-aarch64-apple-darwin.tar.gz
xattr -d com.apple.quarantine crane-{tag}-aarch64-apple-darwin/crane
sudo mv crane-{tag}-aarch64-apple-darwin/crane /usr/local/bin/
crane --version
# PowerShell
Invoke-WebRequest https://github.com/VishuKalier2003/Agentscript/releases/download/{tag}/crane-{tag}-x86_64-pc-windows-msvc.zip -OutFile crane.zip
Expand-Archive crane.zip -DestinationPath "$env:LOCALAPPDATA\Crane"
$bin = "$env:LOCALAPPDATA\Crane\crane-{tag}-x86_64-pc-windows-msvc"
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$bin", "User")
# open a new terminal, then
crane --version
# Rust 1.89 or newer
cargo install --git https://github.com/VishuKalier2003/Agentscript --locked
crane --version

CLI

The rules and the referee

One binary that creates signed selection contracts, validates and tests them, enforces them in the agent's hooks, and syncs the evidence. Governance commands refuse to run inside an agent session.

  • Preserve and target lines in any language with comments
  • Policies, checkpoints, zones, and flows in .crane/
  • Hooks for Claude Code, Codex, Copilot CLI, and Gemini CLI
  • Alert rules with Slack, Jira, and WhatsApp delivery

Extension

Governance from the editor

Select code, press Ctrl Alt F, and preserve it, target it, or make it a zone. The overview shows what passes and which agents are working where.

  • Grouped, searchable actions with a step-by-step plan
  • Governance graph of zones, flows, and selections
  • Connect zones into flows, checked for cycles
  • Decorations, hovers, and code lenses on every selection
