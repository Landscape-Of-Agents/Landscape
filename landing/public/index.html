What is Crane

A prompt is not a rule. A contract is.

Agents edit faster than anyone can review. Crane turns what may change into signed contracts and enforces them where the agent acts.

01

Preserve and target

Lines an agent must not touch, and lines it must change. Markers move with the code.

02

Checked before it runs

Every tool call is decided in the agent's hooks. Shell bypasses are caught after.

03

Signed evidence

Hash-chained records show what each agent did, what was denied, and why.

Product

One rulebook, three ways in.

Write a rule once in the terminal or the editor. Every agent meets it in its hooks, and every decision lands on the dashboard.
